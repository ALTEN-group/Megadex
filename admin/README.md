# Admin

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 21.1.1.

## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.

For the full stack (Megadex + Gatelin + Foxnox + mocks + Traefik), prefer starting from the repo root:

```bash
./scripts/start-dev.sh
```

Admin is then available at `http://localhost:8300/megadex/`.

## Running end-to-end tests

E2E tests use [Playwright](https://playwright.dev/) against the docker-compose stack (Traefik on port 8300).

1. From the repo root, set up and start the stack:

```bash
./scripts/setup-env.sh
./scripts/start-dev.sh
```

2. Run the containerized suite from the repo root:

```bash
./scripts/e2e.sh
```

Or from `admin/`, install the browser once and run the suite locally:

```bash
npm run e2e:install
npm run e2e
```

Interactive UI mode:

```bash
npm run e2e:ui
```

Credentials default to the seeded dev user generated by `setup-mocks.sh` (read from `swagger/src/megadex.openapi.json`). Override with:

```bash
E2E_EMAIL=admin@example.com E2E_PASSWORD='…' npm run e2e
E2E_BASE_URL=http://localhost:8300/megadex/ npm run e2e
```

## Recording website demos

Start the local development stack with `./scripts/start-dev.sh` from the repository
root, then run from `admin/`:

```bash
npm run demos
```

This runs three Playwright recording scenarios and uses `ffmpeg` (required on
`PATH`) to export H.264 MP4 videos and JPG posters to
`../website/docs/public/videos/`. Install Playwright Chromium with
`npm run e2e:install` if needed. Raw recordings and trim metadata remain in the
ignored `demos/videos/` directory.

Use only a disposable local stack with mock data. The scenarios update a seeded
social network entry and delete the signed-in user's saved table views.
Login uses the existing e2e credentials helper; never record real accounts or
sensitive data.
